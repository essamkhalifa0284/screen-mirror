# المرآة — مرآة على الشاشة

تطبيق سطح مكتب يحوّل كاميرا الكمبيوتر إلى مرآة، علشان تراجع شكلك قبل ما تخرج.

## التشغيل
- دبل كليك على **`تشغيل المرآة.vbs`**
- أو من التيرمنال داخل المجلد: `npm start`

لو نقلت المشروع لجهاز تاني: شغّل `npm install` مرة واحدة الأول.

## مرآة بدون كاميرا
دبل كليك على **`مرآة بدون كاميرا.vbs`**، أو اضغط زرار الشاشة السودا في شريط أدوات المرآة.

وسط الشاشة بيبقى أسود علشان يعكس صورتك، وحواليه **إطار مضيء** بينوّر وشّك زي مرايات التسريحة. الماوس بيختفي.
- **L**: تشغيل أو إيقاف الإطار. لما تقفله، إضاءة شاشة اللابتوب بتقل لأقل درجة علشان الأسود يبقى أغمق، وبترجع زي ما كانت لما تخرج.
- **↑ / ↓**: عرض الإطار، **← / →**: لونه من بارد لدافي، **+ / -**: قوة إضاءته
- **مسافة** أو نقرة: تطفي الشاشة خالص. ده أقوى انعكاس بس من غير إضاءة. حرّك الماوس علشان ترجّعها.
- **D**: تقليل إضاءة الشاشة أو إرجاعها
- **Esc**: خروج

نصايح علشان الانعكاس يبقى أوضح:
- الانعكاس بيبقى قوي على الشاشات اللامعة (Glossy)، وضعيف على الشاشات المطفية (Matte / Anti-glare).
- خلّي النور على وشّك، والمكان اللي وراك أضلم.
- لو عايز مرآة حقيقية، فيه لاصقة شاشة عاكسة (Mirror screen protector).

## نسخة الموبايل (أندرويد وآيفون)
**افتحها من هنا:** https://essamkhalifa0284.github.io/screen-mirror/

الكود بتاعها في مجلد `docs`. ده تطبيق ويب (PWA) بيشتغل من المتصفح، وتقدر تثبّته على الموبايل:
- **آيفون (Safari):** زرار المشاركة ← "إضافة إلى الشاشة الرئيسية"
- **أندرويد (Chrome):** القائمة ⋮ ← "تثبيت التطبيق" أو "إضافة إلى الشاشة الرئيسية"

فيه مرآة بالكاميرا الأمامية (إضاءة حوالين المرآة، تكبير بإصبعين، تجميد، التقاط صور، تبديل الكاميرا)، ومرآة بدون كاميرا (شاشة سودا وإطار مضيء). الشاشة بتفضل منوّرة وهي مفتوحة، والتطبيق بيشتغل من غير إنترنت بعد أول مرة.

الكاميرا محتاجة رابط https، علشان كده النسخة دي بتترفع على GitHub Pages.

## المميزات
- صورة معكوسة زي المرآة الحقيقية، ومعاها زرار **"كما يراك الآخرون"** لعرض الصورة من غير عكس
- **إضاءة حول المرآة** (Ring light) تنوّر وشّك في الأوضة الضلمة، وتقدر تتحكم في قوتها ولونها (بارد/دافئ)
- أشكال: مستطيل، حواف ناعمة، بيضاوي، دائرة
- تكبير الصورة، وتعديل السطوع، وخطوط تساعدك تتأكد إن الهدوم مستقيمة
- تجميد الصورة، والتقاط صورة تتحفظ في `الصور\Mirror`
- نافذة من غير إطار، تقدر تسحبها من أي حتة وتكبّرها أو تصغّرها من الركنين اللي تحت، وتفضل فوق كل النوافذ
- **Ctrl+Shift+M** يظهر المرآة أو يخفيها من أي برنامج
- الكاميرا تقفل لوحدها لما تصغّر النافذة

## الاختصارات
| المفتاح | الوظيفة |
|---|---|
| مسافة | تجميد / متابعة |
| F | قلب الصورة |
| L | الإضاءة |
| S | التقاط صورة |
| G | خطوط الاستقامة |
| + / - / 0 | تكبير / تصغير / رجوع للحجم الأصلي |
| عجلة الماوس | تكبير الصورة |
| Ctrl + عجلة الماوس | تغيير حجم النافذة |
| F11 أو دبل كليك | ملء الشاشة |
| Ctrl+Shift+M | إظهار / إخفاء من أي مكان |
